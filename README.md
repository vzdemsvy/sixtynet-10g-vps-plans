## “10G 网络”标的是哪个 10G？

这是整篇文章最该讲清楚的地方。10Gbps 这个词在 VPS 售卖页上至少有三种含义，SixtyNet 用的是第一种。

**网络档位。** 官网写的是“10G Premium Network”，和“2G Premium Network”“4G Premium Network”并列，构成 2G/4G/10G 三档。它描述的是这台机器接入的网络规格，不是“保证给你 10Gbps 独享”。页面上没有公布任何一档的持续吞吐测试值，也没有出现“dedicated”“guaranteed”这类词。

**持续吞吐。** 同样是 10Gbps 端口，能不能长时间跑满，各家做法差很多。有欧洲商家把不限量 10Gbps 端口的入门价压到 €9.99/月，但会在套餐页明写该档持续吞吐只有约 1–2 Gbps，想要 7×24 跑满 10Gbps 得买 €659/月起的独立服务器。SixtyNet 没有公布这类分级数据，所以合理的预期是：短时突发能用上端口能力，长时间满速没有承诺。

**月流量额度。** 这一项 SixtyNet 写得很清楚：5TB、10TB、20TB、40TB。但官网没有说明这是上下行合计还是分别计算。有些商家会把额度拆成“10 TB IN + 10 TB OUT”两个独立限额，买 10TB 实际只能单向跑 10TB，双向加起来就超了。SixtyNet 属于哪种口径，下单前值得确认一句。

还有一个技术前提：单条 TCP 连接在广域网上通常跑不满 10Gbps，TCP 拥塞控制会把你压在线速以下。真正的 10G 负载要用并行流，多连接、分片上传、多线程客户端。你买的是端口能力，不是单线程速度。

## 哪些人不该买

**要 7×24 真 10Gbps 的。** VPS 这个品类给不了。共享端口的持续吞吐永远受同宿主机其他用户影响，想要独享 10Gbps 就得上升独立服务器，那是另一个数量级的预算。SixtyNet 页面也没有承诺过独享。

**只跑 1Gbps 就够的个人站。** 一台 2 核 2G 的普通 VPS 月付几美元就能解决，买 10G 档纯属浪费。SixtyNet 这条产品线本来就是给大流量和特定 IP 属性需求设计的。

**想建站又要住宅 IP 的。** 80/443 被封这一条就过不去，除非你接受非常规端口或前置反代。

**需要欧洲机房的。** SixtyNet 全部产品在美国洛杉矶和尔湾，没有欧洲节点。目标用户在欧亚的话，物理延迟绕不过去。

## 防护与责任边界

LAX 系列标了 DDoS Protection，但官网没有说明是常开还是检测到攻击后才启动的反应式防护。这个区别很实际：反应式防护在识别和处理攻击的窗口期，服务可能受影响；常开防护不会。如果你要靠它扛攻击，得先问清楚。

有些责任明确在用户这边：防火墙规则、系统和服务更新、把备份放在服务器之外。这些不是商家的事，出事也不能指望退款兜底。

退款政策方面，官网没有公布统一的无理由退款期。唯一写明的是 IRVINE-PRO 系列——退款只退到网站余额，不退回原支付渠道。这跟“14 天无理由退款”是两回事，别混着理解。

**流量用超会停机吗？**
